# Origineer-Official.github.io

> 我的个人主页 · My personal homepage

🔗 在线访问：<https://origineer-official.github.io>

## 关于

中国人民大学统计学院大二在读。关注人文社科、音乐与游戏，未来希望在投资理财与 AI4Science 方向深入学习和研究。

## 技术栈

纯静态站点，无框架、无构建步骤：

- **HTML5** — 语义化结构
- **CSS3** — 自定义属性、渐变文字、毛玻璃、网格与响应式布局
- **原生 JavaScript** — IntersectionObserver 滚动动画、鼠标跟随光晕
- **GitHub Pages** — 静态托管

## 本地预览

直接双击 `index.html` 即可，或在目录下启动一个本地服务器：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件结构

```
.
├── index.html   # 页面结构与内容
├── style.css    # 全部样式
├── script.js    # 交互脚本
└── README.md
```

## 自定义

页面内容全部集中在 `index.html`，颜色与主题变量位于 `style.css` 顶部的 `:root` 中，修改即可换肤。
